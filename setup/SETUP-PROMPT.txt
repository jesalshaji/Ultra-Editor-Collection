You are installing "Ultra Edit" - an AI video-editing skill that edits a talking-head / screen recording end to
end inside the user's OWN video editor, through MCP connectors. Follow these rules and steps exactly.

RULES
- Go ONE STEP AT A TIME. For each step: say in one line what it does, run the command yourself when you are
  allowed to (ask first), or tell the user exactly what to click inside the app. Then CHECK it worked before
  moving on. Never paste every step at once.
- Only do the parts for the software the user picks.
- Windows commands are shown; on macOS use the brew / path equivalents (Premiere route is Windows only).
- The full step list lives in skills/ultra-edit/INSTALL.md in this folder - read it and follow it.

STEP 1 - BASICS (everyone): check node --version (18+), python --version (3.10-3.12), ffmpeg -version.
Install only what is missing (winget install OpenJS.NodeJS.LTS / Python.Python.3.12 / Gyan.FFmpeg).
Reopen the terminal after installing.

STEP 2 - THE SKILL: copy the whole folder <REPO>/skills/ultra-edit (SKILL.md + INSTALL.md + effects/) to
~/.claude/skills/ultra-edit/ (Claude Code). Claude Desktop / claude.ai: zip that folder and upload it in
Settings > Capabilities > Skills.

STEP 3 - THE CONNECTOR FOR THEIR SOFTWARE: follow the INSTALL.md section(s) chosen in Step 0, step by step.
   Premiere: npm install -> node scripts/install-panel.js -> Python venv with faster-whisper numpy pillow ->
             claude mcp add ultra-premiere ... -> restart Premiere -> Window > Extensions > Ultra Premiere (green).
   After Effects: scripting preference ON -> Window > Extensions > Ultra Premiere (or the AfterEffectsMCP).
   DaVinci: npx -y davinci-resolve-mcp@latest setup --clients all -> free edition: the resolve_bridge script.

STEP 4 - VERIFY: ask the user to start a NEW Claude session (MCP servers load at start), then check:
   Premiere: "check my Premiere status"     After Effects: "check my After Effects link"
   DaVinci:  "check my DaVinci Resolve status"
Fix anything that fails with the troubleshooting notes in INSTALL.md before finishing.

STEP 5 - TEST EDIT: the user gives any short recording (10-60 s) and says "ultra edit this video".
The assistant transcribes it, proposes hooks + a beat plan, waits for OK, builds a layered timeline in their
editor with captions that follow the voice, and exports. It never uploads or posts anything.

NOT INCLUDED: music (bring a track you have rights to), sound-effect files, app logo files (fetched on demand),
other people's footage, and any personal editing style - the skill uses neutral defaults, and its effects toolkit
(zooms, spotlights, real logos, captions, transitions) only when you ask for an effect.

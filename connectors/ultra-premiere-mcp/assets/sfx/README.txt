Put your own licensed sound effects here, one folder per kit:

  assets/sfx/<kit>/click_1.wav, swish_1.wav, riser_1.wav, impact_1.wav, subboom_1.wav ...

This repo ships no audio. Optional peaks.json: { "<kit>/<name>": { "peak_ms": 4.0 } } - the transient
time in ms, so add_sound_effects lands the hit exactly on the frame.
